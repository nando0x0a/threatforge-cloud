### Observable Behaviour Patterns (for detection tuning)
Given the vulnerability characteristics — unauthenticated network-exploitable broken authentication enabling data tampering against Microsoft Exchange Online [1][2][3] — analysts should monitor for:

1. **Authentication anomalies:** Successful Exchange API or EWS access from sessions with absent, malformed, or replayed authentication tokens.
2. **Unexpected data modification events:** Bulk mailbox item modifications, rule creation, or delegate permission changes from sessions with no prior authenticated history.
3. **No-privilege access to privileged operations:** Exchange admin operations (e.g., transport rule changes, connector modifications) initiated without corresponding RBAC roles.
4. **Anomalous geographic/ASN access:** Exchange Online access from IPs inconsistent with the tenant's baseline, particularly with no MFA challenge recorded.
5. **High-volume unauthenticated probing:** Repeated 200/302 responses to Exchange endpoints from single source IPs without valid session cookies or Bearer tokens.

### Priority Context
This vulnerability is rated CVSS 10.0 CRITICAL [1], is only 5 days old, is network-exploitable with no privileges or user interaction required (AV:N/PR:N/UI:N) [1][2], and has confirmed RCE potential. Even absent a public PoC, the attack surface (Exchange Online, cloud-hosted) makes active scanning plausible. Treat any Exchange Online authentication anomaly as high-priority pending further IoC development.
