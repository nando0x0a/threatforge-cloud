## Behavioural Patterns (Observable, No Static IoC)

Given 100 public PoCs exist [7] and active exploitation is confirmed by both CISA [2] and VulnCheck KEV [3], analysts should monitor for:

1. **Outbound DNS/LDAP/RMI from application servers** — Any unexpected outbound connection from a Java application server to an external host on TCP/UDP 389 (LDAP), TCP 636 (LDAPS), TCP 1099 (RMI), or DNS query to an external host triggered by inbound HTTP request processing
2. **Java class loading from remote host** — Network connections followed by class file retrieval (HTTP GET `.class` file from attacker infrastructure)
3. **Unexpected child processes from Java application servers** — `java` spawning `sh`, `bash`, `cmd.exe`, `powershell`, `curl`, `wget`
4. **Log4j version in use ≤2.14.1** — Presence of `log4j-core-2.x.x.jar` where x.x ≤ 14.1 [1][5]
5. **JNDI strings in any inbound HTTP field** — Headers including X-Forwarded-For, Referer, Accept, X-Api-Version, Authorization, and all body parameters
